# Чекинатор ключей
## Общая инфа
multipart/form-data — это MIME‑тип (формат данных), который используют, чтобы отправлять через HTTP‑запрос сразу и текстовые поля, и файлы — в одном POST‑запросе.

Чаще всего multipart/form-data применяют в веб‑формах, где есть загрузка файлов (фото, документы, видео). Если форма содержит <input type="file">, атрибут enctype у тега <form> должен быть именно multipart/form-data. Иначе загрузка файлов не сработает корректно.

В одном HTTP‑теле запроса данные разбиты на части (parts), каждая часть — это отдельное поле формы или файл. Части разделяет специальная строка‑разделитель (boundary), которую браузер генерирует автоматически.
Упрощённый вид HTTP‑запроса:
```
POST /upload HTTP/1.1
Host: example.com
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="username"

Alice
------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="avatar"; filename="photo.jpg"
Content-Type: image/jpeg

[бинарные данные файла photo.jpg]
------WebKitFormBoundary7MA4YWxkTrZu0gW--
```
* boundary — уникальная строка, которая разделяет части. Не должна встречаться внутри данных.
* Content-Disposition — указывает имя поля (name) и, если это файл, его имя (filename).
* Content-Type для каждой части — тип данных (например, image/jpeg для картинки или по умолчанию text/plain для текста).
* Завершающая граница содержит два дополнительных дефиса в конце (-- после boundary), показывая, что тело запроса закончилось.
